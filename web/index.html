01 / SEGMENTATION

Five zones.
Explicit trust between them.

These RFC 5737 example ranges are a proposed lab plan, not BruteHost addresses. Each boundary receives a documented purpose and a default-deny policy.

VLAN 10 · ADMIN

Control plane

Named operator devices reach only approved management endpoints.

VLAN 20 · SERVER

Core services

DNS, DHCP and time services with tightly scoped upstream access.

VLAN 30 · APPLICATION

Service plane

Application flows are limited to explicit dependencies and ports.

VLAN 40 · TESTING

Isolated experiments

No route to production zones; disposable failure scenarios only.

VLAN 50 · MONITORING

Read-only signals

Health checks target named endpoints without management access.

Designed VLANs and firewall policy · no physical VLAN or OPNsense appliance is deployed.
